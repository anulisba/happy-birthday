# A Little Birthday Surprise

A single-page React + Vite birthday website with an interactive, one-image-at-a-time reveal.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

The numbered image files are displayed in reverse filename order to restore the original upload order. Click **Open your surprise**, then use **Next surprise** and **Back** to move through all 14 images. Keyboard arrow keys also work.
